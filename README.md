# 📰 Jornal DM — Informação, Credibilidade e Inovação

O **Jornal DM** é uma plataforma digital de notícias desenvolvida com o propósito de conectar pessoas à informação, oferecendo uma experiência moderna, intuitiva e dinâmica de acesso aos principais acontecimentos.

Mais do que um portal de notícias, o projeto busca unir tecnologia, comunicação e experiência do usuário, trazendo uma interface moderna, navegação organizada e recursos que tornam o consumo de informações mais acessível.

## 🚀 Tecnologias utilizadas

O desenvolvimento do Jornal DM contou com tecnologias modernas para garantir organização, desempenho e flexibilidade:

- **Ruby on Rails:** framework responsável pela estrutura do sistema, gerenciamento das funcionalidades e processamento das informações.
- **Tailwind CSS:** framework CSS utilizado na construção de uma interface responsiva, moderna e visualmente consistente.

## ✨ Principais funcionalidades

- Portal de notícias com apresentação dinâmica de conteúdos.
- Organização e filtragem de notícias por categorias.
- Área administrativa exclusiva para gerenciamento e publicação de notícias.
- Sistema de autenticação e validação de acesso administrativo.
- Interface responsiva, adaptada a diferentes dispositivos.
- Animações e elementos visuais para proporcionar uma navegação mais fluida.
- Organização de conteúdos por data e relevância.

## 🎯 Nossa proposta

O Jornal DM nasceu com a proposta de transformar a maneira como a informação é apresentada no ambiente digital, valorizando a clareza, a agilidade e a experiência de quem acompanha as notícias.

**Jornal DM — Informação que conecta. Credibilidade que transforma.**
